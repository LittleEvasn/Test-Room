# Witchlings VFX Lab — 별빛탄 1차 테스트

이 프로젝트는 **네가 올린 별 이미지를 직접 활용**한 독립 실행형 Godot 4.x VFX 테스트 프로젝트입니다. 본게임 코드나 원본 저장소를 건드리지 않습니다.

## 실행 방법

1. 압축을 풀고 **Godot 4.x (4.6 권장)**를 엽니다.
2. `Import`에서 이 폴더의 `project.godot` 파일을 선택합니다.
3. Godot 오른쪽 상단 **▶ 프로젝트 실행(F5)**을 누릅니다.

## 조작

| 입력 | 기능 |
| --- | --- |
| 자동 | 0.72초 간격으로 별빛탄 발사 |
| 마우스 왼쪽 | 해당 위치로 표적 이동 + 즉시 발사 |
| Space | 별빛탄 수동 발사 |
| R | 자동 발사 켜기/끄기 |
| 위 / 아래 방향키 | 파티클 밀도 0~3배 조절 |
| C | 초기화 |

## 포함된 VFX

- `assets/star_bolt.png`: 사용자가 제공한 별 이미지에서 밝은 내부를 보존하면서 배경을 투명 처리한 테스트용 텍스처
- `assets/spark.png`: 새로 생성한 작은 원형 노란 파티클 텍스처
- `scripts/star_bolt.gd`: 회전하는 별 이미지 + 이동 잔광 + 낙후성 노란색 파티클 (CPU에서 직접 그리는 방식)
- `scripts/impact_burst.gd`: 명중 시 반짝이 + 확산 링
- `scripts/main.gd`: 발사 시뮬레이터, 표적, 키보드 조작

## 본게임 적용 전 확인

1. 별 크기/색/꼬리 길이를 실제 게임 배경과 비교한다.
2. 기존 실전 마법 로직에 별빛탄 노드/자체 파티클을 연결한다.
3. 몬스터 밀집 상태에서 동시 발사 수에 따라 프레임 시간을 측정한다.
4. 실제 판정 위치와 명중 시각 효과 위치가 일치하는지 확인한다.

**참고:** 독립 실행 편의를 위해 GPU 파티클 노드를 쓰는 대신, `Node2D._draw()`로 작은 입자를 그려낸 첫 번째 시제품입니다. 시각적 결과를 확인한 후 `GPUParticles2D`로 교체하거나 풀링하는 방식도 가능합니다.

**검증 상태:** 소스/리소스 구성과 압축 패키지 생성 완료. 이 환경에는 Godot 실행기가 없어 실제 엔진 실행까지 확인하지 못했습니다.
